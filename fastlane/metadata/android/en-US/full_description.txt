Ares (formerly Hermes Android) is a free, open-source client for your own Hermes Agent server. Connect a phone or tablet over LAN, Wi-Fi, a private Tailscale network or a configured HTTPS endpoint.

Choose Classic or NextGen in Settings. Both interfaces share saved gateways and chats.

Features:
• Stream replies, exposed reasoning and tool activity
• Switch between Classic and the Kyllene-style NextGen interface
• Sign in once through the Hermes dashboard with password or browser authentication
• Search, pin, archive and reopen chats, with unread and running states
• Choose models and thinking effort, including default, fallback and auxiliary model settings
• Attach photos and files, and open delivered files as download, open and share cards
• Follow goals, live tasks and subagents from the NextGen session dock
• Review inline approvals and questions, with reply and approval notifications
• Inspect Insights, Capabilities, scheduled jobs, projects, memory and skills
• Dictate messages and use Android text-to-speech for spoken replies
• Use dark, light or system themes, Classic palettes and NextGen accents
• Open the privacy policy and report unsafe or offensive AI output
• Connect through a remote Gateway JSON-RPC socket or the REST/SSE API transport

Background delivery needs the separately installed and authorised mobile-push server companion. Device battery controls, offline networks and server availability can delay work.

Ares requires a running Hermes Agent server that you can reach from the device. It does not include a hosted Hermes account, model subscription or server installation.

NextGen adapts Kyllene by Giton22 (MIT). See the repository notices for licence details.
