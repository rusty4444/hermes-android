# Ares 4.0.4

Stable patch release `4.0.4+3061`. ABI split codes `30611` (armeabi-v7a),
`30612` (arm64-v8a) and `30613` (x86_64), each above the highest published
4.0.3 split (`30603`). The production package `com.hermesagent.hermes_android`
and signing certificate are unchanged; install over the existing app.

Covers all changes since 4.0.3.

## Fixed

### NextGen back gesture closes the sidebar (#278)

In NextGen mode the back gesture opened the chat sidebar, but a second back
exited the app instead of closing the sidebar. The main screen wraps its
`Scaffold` in `PopScope(canPop: false)`; Flutter's `ModalRoute.popDisposition`
lets that veto win over the drawer's local-history entry, so the second back
reached the handler with the drawer open and called `SystemNavigator.pop()`.

The handler now closes the drawer when it is open (the close animation clears
the local-history entry). Back with the sidebar closed still opens it, so the
gesture is an open/close toggle. Pushed pages (Settings, Scheduled, …) still
pop normally first.

Download the APK for your device from the release assets and install over the
