# Hermes Android 3.2.3

## Resumable voice drafts

While reading a long reply, record one short comment, pause to read the next
section, then continue recording another comment. Preview the combined draft and
send it as one message rather than several fragmented prompts. Pausing and
returning to the chat preserve the draft. Active recording keeps the screen
awake; stopping, leaving or backgrounding releases that flag.

Send uses the configured Hermes Dashboard transcription endpoint, with existing
authentication and profile selection, then submits the recognized text through
the existing chat transport. It does not contact a Whisper endpoint directly or
add another recognition service. Unrelated typed text and selected attachments
remain intact. A correlated admission acknowledgement, response activity on the
active request, or authoritative receipt is required before discarding audio; a
socket write alone is insufficient. Ambiguous delivery retains the draft for
manual review, with no automatic prompt resubmission.

Recordings are capped at ten minutes and 6 MiB. The server must expose the
existing authenticated Dashboard transcription route and have STT configured;
API-only connections without that route retain the recording on failure. The
recorded audio itself is not archived as a playable attachment in chat history.

## Scroll pause preservation

When the same ongoing stream is observed more than once, `beginStreaming` can
reset the reader's manual pause. It is now idempotent while the stream is
active, so repeated snapshots cannot silently re-enable following. A genuinely
new stream still chooses its initial state normally.

## Workspace viewport restoration

The nested workspace can retain an incorrect viewport across keyboard and
Activity transitions. Its inner shell now owns keyboard resizing instead of
resizing both Scaffold layers. Fresh insets and layout are requested on the
attached Android root after resume/new-intent transitions, without caching or
inventing a keyboard height.

## Defensive shared-intent parsing

Shared intents can contain unexpected `Parcelable` values in `EXTRA_STREAM`.
The app now avoids typed casts that assume every value is a `Uri`, retains
valid `ClipData`, and filters mixed multiple-share lists to valid URIs while
preserving de-duplication. Extraction errors are contained on the existing
worker boundary.

## Ukrainian locale and language selector

A device language alone cannot select a locale absent from the application
catalogue, and users cannot choose a different supported language in the app.
Ukrainian is now included in the catalogue, and a Settings selector is
available for every generated locale plus the system default. Locale changes
apply through the existing root refresh without replacing the Navigator. The
choice persists and is included in the existing configuration backup allowlist.
Restored preferences update the running root too.

## Upgrade

Version 3.2.3, base 3029, ABI codes 30291 / 30292 / 30293. The production
package, signer and accepted upgrade floor remain unchanged. Install over the
existing app without uninstalling or clearing data. Updating the APK does not
install or reconfigure host software, provider credentials or the mobile-push
companion.

## Verification and limits

Publication is pending source review, analysis, tests, signed builds, CI and
verification of downloaded release assets. The GitHub release body records the
completed checks for the immutable publication commit. Automated widget and
local HTTP fixtures do not establish real-device or provider failover results.

Hermes Agent assisted with independent review, integration tests and release
preparation. Physical-device testing remains separate from automated checks.
