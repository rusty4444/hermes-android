# Hermes Android 3.0.4

Version **3.0.4+3008** resolves the documented licence-evidence and third-party
notice-delivery questions. Application code remains under its existing MIT
terms. This release does not change chat, gateway, authentication or
notification-consent behaviour.

## Upgrading

Export an encrypted configuration backup before updating and keep its password
safe. Install the matching production-signed APK over the existing app; do not
uninstall or clear app data. Package `com.hermesagent.hermes_android` and the
production signing identity remain unchanged.

Base code `3008` yields `30081` for ARMv7, `30082` for ARM64 and `30083` for
x86_64. Every split is above the highest 3.0.3 code, `30073`. Debug builds retain
the separate `.dev` package and are not production upgrades.

## Existing MIT terms, not a new contributor grant

The historical README declared MIT before the community contributions and
retained it throughout PR #88's 56 source commits. The contribution audit covers
132 merged PRs through 3.0.3, including all 34 externally submitted PRs, with
immutable common-base/head/merge and notice-blob evidence.

GitHub's applicable contribution terms license additions under the repository's
noticed licence, subject to a superseding separate agreement. No contrary
public contribution terms were identified in this audit. The missing historical
`LICENSE` filename and an unanswered later confirmation request are not evidence
that the earlier declaration did not exist. The full canonical application MIT
text and clarified NOTICE were already included in 3.0.3.

See [the evidence and policy sources](../licensing/README.md) and
[the exact contribution index](../licensing/contribution-evidence.json). No
contributor's silence is treated as consent, copyright ownership is not assigned
to the maintainer, and original history and credits are preserved.

## Targeted third-party notice retention

This release preserves separate upstream copyright, permission and warranty
texts for identifiable copied materials:

- Safi Shamsi's historical MIT terms for the generated Graphify viewer template.
- Nous Research's MIT terms for copied backend message templates in fixtures.
- Apache-2.0 terms for Gradle wrapper build materials accompanying the embedded
  Library's unchanged source archive.
- Flutter's BSD-3-Clause terms for the identified generated scaffold.

The [scoped inventory](../../third_party/NOTICE.md) distinguishes source/build
materials from runtime dependencies. Additional local notices use the existing
**Settings → About → Licences** surface and accompany the source distribution.
Cinzel OFL, the embedded distributor's LGPL-2.1-or-later terms, its complete
source/relink materials and other dependency notices remain intact. The retained
hash-bound upstream Library archive is not rewritten.

## Compatibility and delivery limits

- No Hermes host deployment, gateway restart, server configuration change or
  app-data reset is required. Existing transport and background-push prerequisites
  remain unchanged.
- No new feature from an unmerged PR is included. The 3.0.3 chat, preview,
  recovery, backup and notification behaviour is retained.
- The historical grant evidence and notice corrections do not constitute a
  universal originality warranty, a court determination or automatic F-Droid
  acceptance. Reproducible-build results and reviewer acceptance are reported
  separately in the F-Droid merge request.
- Checksums, APK notice comparisons and source/relink associations establish
  distribution identity and source correspondence, not independent build
  provenance or physical-phone acceptance.

Thanks to the original contributors and F-Droid reviewers. Hermes Agent assisted
with historical evidence collection, independent audits, implementation,
release validation and regression tests. Existing credits and release history
are preserved.
