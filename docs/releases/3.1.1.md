# Hermes Android 3.1.1

Stable patch release. Release identity is `3.1.1+3014`; production APK codes are
`30141`, `30142` and `30143`, above every 3.1.0 and 3.1 RC split.

## Changed

- REST/API-server transport now handles `event: approval.request` frames instead
  of crashing on the non-object `choices` list. Approval frames are forwarded
  into the existing approval dialog, and the responder falls back to
  `POST /v1/runs/{run_id}/approval` when no Desktop Gateway session is
  available (#229).

## Compatibility

- Production package `com.hermesagent.hermes_android` and signing identity are
  unchanged.
- Upgrades 3.1.0 and every 3.1 RC in place. Do not uninstall or clear app data.
- Export an encrypted configuration backup before updating.

## Verification

- `flutter analyze` clean.
- `flutter test` passed all tests.
- Release CI verified split version codes, the established production signer,
  and produced all 3 APKs + SHA256SUMS.
