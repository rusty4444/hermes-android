## Implemented Usage scope

One **More → Usage** section covers **Nous, OpenRouter, OpenAI, Claude and
DeepSeek**, rather than parallel competing usage entry points.

- Hermes-recorded activity/model analytics remain distinct from provider-account
  allowance. Subscription windows come from the selected-profile host's
  `model.options` response, independently of recorded usage loading.
- **OpenAI Codex subscription allowance is separate from paid OpenAI API access.**
  Only exact `openai-codex` inventory supplies Codex allowance; paid `openai`
  analytics do not establish subscription allowance. **Claude OAuth allowance is
  separate from paid Claude API access**, using the exact `anthropic` inventory.
- **Session and weekly remaining percentages and reset times appear only where
  the backend actually reports them**, including model-specific window labels
  and scope. Missing/malformed percentages or reset times stay unavailable rather
  than becoming zero, unlimited or an inferred allowance. **Daily quotas are not
  exposed.** No token/monetary allowances, balances, pricing or entitlements are
  invented from recorded usage.
- Account pools preserve individual account labels, state and windows, not an
  averaged allowance. Model-scoped exhaustion does not establish account-wide
  exhaustion; an empty/malformed accounts field does not fall back to pooled data.
- Allowance and analytics load independently, support explicit refresh/retry and
  retain prior successful values with stale/error copy on failed refresh. New
  quota strings use **English fallback in non-English locales**; this is not a
  claim of complete quota-string translation.
- Saved dashboard origin/prefix, authentication, selected-profile routing and
  client-certificate boundaries remain in force. No provider credentials are
  collected on the phone and no permission check is weakened for availability.

Endpoint support, account mode and response shapes remain host-dependent. An APK
update does not install host features or make an unsupported allowance available.
