# Hermes Android 3.2.2

## Fallback providers and models

Open **More → Agent → Model** to edit the selected Hermes profile's fallback
chain. Add rows, choose provider/model pairs, delete rows or change their order.
Tap **Save fallback list** to apply the complete primary chain. An empty list
removes its entries. Legacy `fallback_model` entries appear in a separate
read-only section and remain active; change those on the Hermes host.

The editor preserves existing unknown models and routing metadata. Custom routes
stay protected from provider/model-only edits. Host rejection or a readback
mismatch leaves the save unconfirmed. Opening the screen changes nothing.
Profile defaults, auxiliary assignments, cron pins and chat overrides retain
their existing controls.

See [model management](../model-management.md) for host requirements and limits.
Fallback editing requires a host that advertises raw saved-config reads in its
OpenAPI schema. Older or unverified hosts leave this editor unavailable; main
and auxiliary model controls remain independent.

## Upgrade

Version 3.2.2, base 3028, ABI codes 30281 / 30282 / 30283. The production package,
signer and accepted upgrade floor remain unchanged. Install over the existing
app without uninstalling or clearing data. Updating the APK does not install or
reconfigure host software, provider credentials or the mobile-push companion.

## Verification and limits

Publication is pending source review, analysis, tests, signed builds, CI and
verification of downloaded release assets. The GitHub release body records the
completed checks for the immutable publication commit. Automated widget and
local HTTP fixtures do not establish real-device or provider failover results.

Hermes Agent assisted with implementation, review, tests and release preparation.
