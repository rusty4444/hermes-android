# Ares 4.0.2

Stable patch release `4.0.2+3050`. ABI split codes `30501` (armeabi-v7a),
`30502` (arm64-v8a) and `30503` (x86_64), each above the highest published
4.0.1 split (`30493`). Installs over the existing app. Covers all changes since
4.0.1.

## Fixed

### Collapsed session-arc summaries keep the assistant tail

`LegacyLcmSummary.splitEnvelope` extracts the summary envelope from rows where
`absorbed_message_uids` merges it into an assistant turn. The envelope renders
as a collapsed **Summary** card in NextGen while the trailing assistant content
stays visible, instead of being swallowed by the collapse.
