# Ares 4.0.3

Stable patch release `4.0.3+3060`. ABI split codes `30601` (armeabi-v7a),
`30602` (arm64-v8a) and `30603` (x86_64), each above the highest published
4.0.2 split (`30503`). The production package `com.hermesagent.hermes_android`
and signing certificate are unchanged; install over the existing app.

Covers all changes since 4.0.2.

## Fixed

### Full-message text selection

A long-press drag now selects as much of a reply as you want — across
paragraphs, lists and fenced code — instead of being confined to a single
block. Both chat interfaces are covered:

- **Classic:** the long-press **Select text** dialog wraps the whole reply in a
  single selection scope, so one drag spans every paragraph and code block.
- **NextGen:** the inline reply (which has no select-text dialog) previously
  rendered each paragraph and code block as its own selection island. It now
  renders inside one selection scope with plain-text prose and code, so a drag
  sweeps the entire message.

## Install

Download the APK for your device from the release assets and install over the
existing app; do not uninstall or clear app data.

## Verification

- The full Flutter test suite passes, including a regression test that pumps the
  NextGen chat and drags from the first paragraph across a code fence into the
  last; it fails without the fix and passes with it.
- Release APKs are production-signed and verified against the established
  signer SHA-256 `475baf43…f592fb`.

## Not verified

- Live device integration beyond the reporter's phone test of the selection fix.
