# Hermes Android 3.2.6

Stable release, base build **3034** (ABI splits `30341` / `30342` / `30343`).
Every split upgrades the highest previously distributed split, 3.2.5's `30333`,
so it installs in place over 3.2.5. The production package
`com.hermesagent.hermes_android` and signing certificate are unchanged; install
over the existing app rather than uninstalling.

This release covers everything since **3.2.5**.

## Slash-command autocomplete and execution (#269)

Remote Gateway chats now discover and run Hermes slash commands directly from
the message composer.

- **Live catalogue discovery:** when a Remote Gateway chat connects, the app
  requests `commands.catalog` and merges built-in commands (`pairs` and
  `categories[].pairs`), plugin commands (`plugin_commands`), skill commands
  (`skills`), canonical aliases (`canon`), and argument metadata (`commands`).
- **Autocomplete popup:** typing a leading `/` at the start of the composer
  opens a filterable popup above the input bar with category badges and
  descriptions. Selecting a command that takes arguments inserts `/command `
  and keeps the keyboard ready; commands with no required arguments can be
  submitted immediately.
- **Wire-accurate `slash.exec` handling:** leading slash invocations (including
  commands with arguments such as `/title My chat`) are sent over `slash.exec`.
  Plain worker and plugin replies (`{output, warning}`) appear as compact
  dismissible in-chat notices without re-sending the command as a normal
  prompt. Gateway `skill`, `send`, `prefill`, `plugin`, and `alias` directives
  are honoured directly.
- **Safe fallback and delivery-uncertainty protection:** if a gateway does not
  support `slash.exec` or reports the command as unsupported, the app falls
  back to a normal prompt send. If a timeout or disconnect occurs after the
  `slash.exec` frame was already written to the socket, the app keeps your
  composer draft and shows a delivery-uncertain warning instead of re-sending
  the command as a normal prompt.
