Stable patch release. Release identity is `3.1.4+3017`; production APK codes are
`30171`, `30172` and `30173`, above every 3.1.3 and 3.1.2 split.

- README release window now shows exactly the three latest changelog releases,

- Production package `com.hermesagent.hermes_android` and signing identity are
  unchanged.
- Upgrades 3.1.3 and every 3.1 RC in place. Do not uninstall or clear app data.
- Export an encrypted configuration backup before updating.

- `flutter test` passed all tests.

  and produced all 3 APKs + SHA256SUMS.
