# Ares 4.0.1

Stable release `4.0.1+3049`. ABI split codes `30491` (armeabi-v7a), `30492`
(arm64-v8a) and `30493` (x86_64), each above the highest published 4.0.0 split
(`30483`). Installs over the existing app. Covers all changes since 4.0.0 and
promotes the 4.0.1-rc.1 testing candidate (#276).

## Fixed

- **Multi-chat performance.** Switching between chats no longer re-fetches
  multi-MB history pages: a bounded LRU cache keeps the 3 most recently viewed
  transcripts in memory and catches up via event replay on switch-back.
- **Streaming UI coalescing.** Token deltas, reasoning and subagent events batch
  notifications to once per frame instead of rebuilding the transcript on every
  token. Terminal events remain immediate.
- **Bounded tool JSON.** Tool arguments and results are compact-encoded first;
  pretty-printing only runs when the payload fits the 16 KB cap.
- **Throttled session list.** Socket-driven sidebar refreshes debounce to 5 s
  (2 s while the drawer is open) and pause while the app is backgrounded.
- **History skips inline images.** `getMessagesBytes` sends
  `inline_images=false`, avoiding re-transmission of stored data-URI images.

## Added

- **Summary card.** LCM context summaries (Recent, Session Arc, Durable,
  Depth-N) collapse into a dedicated card titled "Summary" with a summarise
  icon. Tap to expand the full body; long-press copies. Localised across all 12
  shipped locales.
