# Hermes Android 3.1.7

Stable release for the LAN discovery feature. Release identity is `3.1.7+3020`;
production APK codes are `30201`, `30202` and `30203`, above every 3.1.6 split.

## Added

- Find Hermes on LAN discovery (IPv4 and IPv6 subnet probing, HTTPS-aware,
  bounded concurrency).

## Fixed

- Test file cleanup in lan_discovery_service_test.dart (removed dead mock
  scaffolding and unused imports).

## Compatibility

- Production package `com.hermesagent.hermes_android` and signing identity are
  unchanged.
- Upgrades 3.1.6 and every earlier 3.1 RC in place. Do not uninstall or clear
  app data.
- Export an encrypted configuration backup before updating.
