# Hermes Android 3.1.2

Stable patch release. Release identity is `3.1.2+3015`; production APK codes are
`30151`, `30152` and `30153`, above every 3.1.1 and 3.1.0 split.

## Fixed

- README release window now shows the three latest changelog releases, matching
  the release validation script.

## Compatibility

- Production package `com.hermesagent.hermes_android` and signing identity are
  unchanged.
- Upgrades 3.1.1 and every 3.1 RC in place. Do not uninstall or clear app data.
- Export an encrypted configuration backup before updating.

## Verification

- `flutter analyze` clean.
- `flutter test` passed all tests.
- Release CI verified split version codes, the established production signer,
  and produced all 3 APKs + SHA256SUMS.
