# Ares - formerly Hermes Android 4.0.0-rc.10

Release candidate **4.0.0-rc.10+3047** (ABI splits **30471**, **30472** and
**30473**). Every split upgrades the published rc.9 splits and the earlier
3046 preview. The production package `com.hermesagent.hermes_android` and signing
certificate are unchanged; install over the existing app rather than
uninstalling it. **3.2.8 remains the latest stable release.**

## Candidate highlights

- Choose **Classic** or **NextGen** during setup, with explanations and the
  ability to switch later. Saved gateways and chats remain shared.
- Per-chat model selection now covers new-session creation, authoritative and
  legacy gateways, expensive-model confirmation, deferred changes, safe retry
  and rollback when the gateway rejects a choice.
- Fenced Hermes code blocks have **Copy code** and line-wrap controls in both
  interfaces, including multiple blocks and code still streaming in NextGen.
- NextGen sidebar searches have a one-tap **Clear search** button that restores
  the full list without backspacing.
- Cron-run conversations have a dedicated **Crons** filter and no longer appear
  as normal chats. **Scheduled** remains the scheduled-job manager.
- NextGen catch-up rejects incomplete, truncated or wrong-epoch replay and falls
  back to transcript recovery. Sidebar refresh bursts are coalesced, and stale
  load-more responses cannot replace a newer list.
- The release also includes the Ares rebrand, dashboard sign-in, attachments,
  live plans and subagents, notifications, long-chat performance work, privacy
  links, AI-output reporting and the separate Play-managed app bundle.

## Verification and acceptance

The source is gated by formatting, fatal-info analysis, the complete Flutter
suite, release-identity checks, Play-distribution tests and the repository's
Python release checks. The GitHub tag workflow builds and verifies the signed
ABI APKs and Play AAB from the committed tag before publishing the release.

Physical-device IME behaviour and multi-chat performance remain acceptance-test
focus areas. Unit/widget tests and the release build do not by themselves prove
those reports are resolved.
