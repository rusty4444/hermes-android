# Hermes Android 3.2.8

Stable release, base build **3036** (ABI splits `30361` / `30362` / `30363`).
Every split upgrades the highest previously distributed split, 3.2.7's `30353`,
so it installs in place over 3.2.7. The production package
`com.hermesagent.hermes_android` and signing certificate are unchanged; install
over the existing app rather than uninstalling.

This release covers everything since **3.2.7**.

## M3 Expressive composer pill and last-reply quick actions (#271)

The chat screen adopts an M3 Expressive floating composer pill alongside tonal
quick-action chips beneath the latest completed assistant reply.

- **Floating composer pill:** the input bar now floats in an elevated tonal
  pill (`surfaceContainerHigh`, 28 dp radius, hairline border and soft shadow)
  with a borderless text field and a formatting toolbar (`code`, `bold`,
  `italic`) that appears only once a draft is present. When the software
  keyboard opens, outer horizontal insets collapse so narrow viewports (`320 dp`
  at `200%` text scale) retain their full editor width.
- **Animated Send FAB:** the Send button renders as a filled accent button that
  morphs from a circle to a squircle while a turn is active, preserving existing
  mid-turn steering and the separate **Stop** control.
- **Last-reply quick actions:** the newest completed assistant reply displays
  40 dp tonal circular chips for **Copy**, **Select text**, **Read aloud** and
  **Regenerate** whenever no turn is running. Long-pressing any quick-action
  chip opens the full message action sheet.
- **Foldable cover-screen layout:** the failed-to-load state scrolls cleanly
  when a foldable cover display has the software keyboard open, backed by
  dedicated foldable viewport tests (`344 dp` cover, `700 dp` inner, and
  `1000 dp` unfolded).
