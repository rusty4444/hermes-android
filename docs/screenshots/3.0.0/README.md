# Hermes Android 3.0.0 screenshot captures

These are actual Android emulator screen captures, not UI mockups or rendered illustrations. Each image uses a different built-in palette; no palette repeats in the README gallery.

- Device: disposable Pixel 7 Android API 35 ARM64 emulator, 1080 × 2400.
- App: production-signed `v3.0.0-rc.3`, installed from its published ARM64 APK. Stable 3.0.0 retains that application code; only release identity, documentation and artwork change.
- Data: an isolated loopback test gateway supplies illustrative conversations and file references. No production account, private chats, credentials, model inference or real tool execution appears in these images. The current-work bar shows a labelled fixture event.
- Capture: Android `screencap`, saved as unedited PNG images. The supplied announcement hero is a separate unchanged JPEG.
- Coverage: phone-sized navigation, light/dark palettes, conversation timestamps, Assets discovery, archive filtering, appearance controls and an active work bar with separate Stop/Send controls. This is not a physical-device push, private-CA or end-to-end save-picker acceptance claim.
