## State/ownership boundaries preserved

- Gateway credentials remain outside both parser and native-player boundaries. File playback uses only authorised bounded local bytes and empty HTTP headers.
- `close()` synchronously revokes commands, joins accepted commands/native creation through the controller's public disposal, and deletes only the exact owned directory after confirmed release. Initialisation failure, uninitialised-event hangs, late creation/commands and rejected disposal are distinct states.
- Same-PID marker exclusion happens **before opening a second descriptor**: POSIX locks are process-wide and closing any descriptor for the same marker can drop that process's lock. Neither timestamps nor `kill(pid, 0)` substitute for the lock.
- Successful route pop/pause is not a native-disposal acknowledgement. No auto-resume, global player-limit claim, weakened budget, broader credential scope or external-viewer execution was introduced.
